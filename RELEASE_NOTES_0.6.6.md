# CraftLive 0.6.6

<!-- CRAFTLIVE:HU -->
## Mi változott?

- A Minecraft-verzió mostantól fixen a legújabb Java Edition kiadás: 26.2.
- A régi Minecraft-verziók, verziókatalógusok és a verzióválasztó teljesen kikerültek.
- A mobválasztó kizárólag a 26.2-es mobokat mutatja, köztük az új Sulfur Cube-ot.
- Az Interakciók és a Hosting külön főfület kapott a bal oldali menüben.
- A Hosting fülön minden felhasználó a saját Falix szerverpaneljének címét mentheti és nyithatja meg.
- A Falix-jelszót a CraftLive nem kéri és nem tárolja.
<!-- CRAFTLIVE:END-HU -->

<!-- CRAFTLIVE:EN -->
## What changed?

- The Minecraft version is now fixed to the latest Java Edition release: 26.2.
- Old Minecraft versions, version catalogs, and the version selector have been completely removed.
- The mob picker now shows only 26.2 mobs, including the new Sulfur Cube.
- Interactions and Hosting now have separate main tabs in the sidebar.
- The Hosting tab lets each user save and open their own Falix server panel URL.
- CraftLive never requests or stores the user's Falix password.
